# 📈 Web Traffic & Conversion Analytics Dashboard

## 📁 Project Overview
This project presents an interactive *Web Traffic & Conversion Analytics Dashboard* built using *Google Looker Studio* and backed by web analytics tracking data (metricslab.net). 
The dashboard monitors user acquisition, page engagement, geographical traffic distribution, device categories, and conversion performance over time to evaluate content reach and digital funnel effectiveness.

---

## 📈 Dashboard Highlights
The dashboard includes the following key visualizations:

1. *Executive Performance KPIs*
   - *Total Page Views:* 8,227 (with sparkline trend)
   - *Total Users:* 5,294 (with user growth sparkline)
   - *Total Conversions:* 106 (with conversion rate sparkline)

2. *Daily Views Trend (Time-Series)*
   - Line chart tracking daily page view fluctuations between April 10 and May 8, capturing initial engagement spikes reaching up to 600+ views before settling into steady baseline traffic.

3. *Geographic Distribution & Global Reach*
   - Interactive world choropleth map paired with a ranked horizontal bar chart of top visitor countries led by the *United States, **United Kingdom, **France, **Germany, and the **Netherlands*.

4. *Top Performing Pages (by Views)*
   - Ranked summary table highlighting high-traffic content:
     - MM Dashboard - metricslab.net: *1,723 views*
     - Courses - metricslab.net: *949 views*
     - Login - metricslab.net: *488 views*
     - Tools Overview - metricslab.net: *377 views*
     - GA4 Migration Walkthrough - metricslab.net: *374 views*

5. *Device Category Breakdown*
   - Donut chart depicting user device distribution across *Desktop, **Mobile, and **Tablet*, highlighting desktop traffic as the primary driver of web interactions.

---

## 💡 Key Insights
The dashboard reveals the following key takeaways:

1. *Core Engagement Asset:* The *MM Dashboard* page is the single largest entry and engagement asset, driving *1,723 views (~21% of all platform views)*.
2. *Educational & Tool Interest:* *Courses* (949 views) and specialized technical resources like the *GA4 Migration Walkthrough* (374 views) demonstrate strong organic user demand for learning and technical implementation content.
3. *Primary Geographic Audience:* The *United States and United Kingdom* constitute the majority of global traffic, representing the primary target regions for user acquisition and product marketing.
4. *Conversion Efficiency:* Out of *5,294 total visitors, the platform captured **106 goal conversions, establishing an overall site-wide conversion rate of approximately **2.0%*.

> *Filter Data:* Use the top control panel (Select date range, Source & Medium dropdown) to dynamically filter traffic channels (organic search, direct, referral, newsletter) and evaluation windows.

## 🎯 Final Conclusion & Digital Recommendations
* *Optimize Top Content Funnels:* Since the MM Dashboard and Courses pages receive the highest view counts, embed clear calls-to-action (CTAs) and sign-up prompts directly within those pages to lift the conversion rate beyond 2%.
* *Mobile Experience Refinement:* Monitor mobile responsiveness for key tools and migration guides to capture and convert users visiting from non-desktop devices.
* *Targeted Organic Content:* Continue developing walkthrough guides (e.g., GA4 migration and UTM tracking tutorials), as technical resources generate consistent, qualified organic search traffic.
